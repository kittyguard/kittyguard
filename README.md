# DG Security

轻量级 Windows 用户态杀毒软件，纯用户态运行，不装内核驱动、不做系统服务、不绑架系统。

## 特性
- 多引擎查杀：ClamAV 900万+签名 + YARA规则 + 黑名单哈希 + ML AI裁决层
- 实时防护：文件事件监控、勒索文档守护、行为链分析
- 资源占用极低：常驻CPU≈0%，内存占用<50MB
- 纯用户态运行：不需要管理员权限常驻，不蓝屏、不拖慢系统
- 支持Windows 10 / 11

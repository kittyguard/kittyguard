WHY DG

为什么选择 DG 安全

杀软不一定非要「进内核」才叫强。DG 把 Windows 用户态能拿到的权限用到极致，换来的是安全、轻量和不被打扰。

纯用户态，零驱动

不加载任何内核驱动，不碰 Ring0。没有蓝屏风险，不跟其他安全软件抢内核控制权，装了就安安静静待着。

user-mode only

轻量到几乎无感

C++ 事件驱动组件毫秒级响应，常驻 CPU 占用约等于 0；快速扫描开箱即快，不再需要牺牲性能换安全感。

6.3.0

已发布自启动实时监控 · 扫描 IO 节流

新增独立实时防线：每 5 秒快照对比注册表 Run/RunOnce（HKCU+HKLM）与用户/全局启动文件夹，发现新增自启动项立即记录防护日志；可疑项（命令含 PowerShell/mshta/rundll32/certutil/bitsadmin 等脚本宿主或下载执行链、从 Temp/AppData/Downloads/Public 可写目录启动、双扩展名伪装）自动弹窗告警，可一键去「工具 → 启动项管理」处理，免打扰模式静默记录；设置新增「自启动监控」开关，纯轮询轻量线程 CPU≈0。扫描节流再升级：扫描线程降优先级之外新增进程级 IO 优先级 VERY_LOW（NtSetInformationProcess IoPriority）——全盘扫描时 DG 的磁盘读写请求自动排到其他程序之后，鼠标/系统/游戏不再被扫描 IO 拖到一卡一卡，扫描结束自动恢复。
